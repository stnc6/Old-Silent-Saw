This mod restores the full, old silent spin for the saw. The base detection radius is set to 5 in-game meters. There is no need to cut the air before making cut. You can make it smaller or larger if you prefer. Simply change the value in the line "local RADIUS_METERS = 5" in the file "true_silent_motor_saw.lua."

INSTALL: Need a SuperBLT. Extract Old-Silent-Saw-main and place it in the PAYDAY 2/mods folder.
